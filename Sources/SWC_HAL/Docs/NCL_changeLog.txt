Version 4.0.1:
    * AES:  Fixed issue AK-993 - [Booter] AES/SHA reset: the booter writes to the wrong register.
            Fixed issue AK-1100 - [SWC_HAL] AES timing issue: fixed AES_WAIT() timeout to scale with AES_SOURCE_CLOCK via USEC_TO_ITERATIONS().
    * ECC:  Changed ECC_PointVer()/NCL_ECC_PointVerify() isVerified parameter from BOOLEAN*/uint8_t* to DEFS_STATUS*/NCL_STATUS_T*.
            Removed redundant PMC_OperCryptoModules() call from ECC_PointMultTest().
    * RSA:  Fix SW HAL issue #921 - Increase PKA memory registers size to 0xC000.
    * SHA:  Configure the FIU DMA request when enabling unlimited burst for SHA flash transfers.
    * DRBG: Add fault-injection / side-channel hardening to the HW SHA-based DRBG driver (flow monitors, secure compares, secret zeroization).
            Fixed entropy health tests returning incorrect failure status codes.
    * MISC: Add security event handler (NCL_MISC_InitSecurityEventHandler()) and NCL_STATUS_SECURITY_ERROR to report security errors
            propagated from lower crypto layers.
            Add PMC_TurnOnCryptoModules() to power-up cryptographic modules with retry.

Version 4.0.0:
    * AES:  Fix SW HAL issue #283 - Added NCL_AES_KEY_SIZE_DO_NOT_CFG to key size enum.
            Fix SW HAL issue #282 - verify the relevant SetParams() function has been called previous to AES_GCM/CCM_Encrypt/Decrypt.
    * ECC:  Integrate PKA driver version 89.
    * RSA:  Integrate PKA driver version 89.
    * MISC: Generate NCL version string dynamically instead of hardcoded text to ensure accuracy

Version 2.0.2:
    * AES: Support capabilities of big/little endian, DPA countermeasure, automatic start,
      key selection and key locking
    * ECC: Use key size 256 for selftest (instead of 521)
    * ECC: Use the global DRBG context to create the an ECC key (using a HKDF callback)
    * HMAC: Clear local temporary buffers of HMAC and HKDF after use
    * DRBG: Add ctxIsReady parameter to the DRBG context, in order to prevent generating random bits
      with an uninitialized (instantiated) context.
    * DRBG: Add security strength parameter to the DRBG context. Now when there is an auto-reseed inside
      the Generate flow, the security strength is maintained.
    * DRBG: Modify entropyInput buffer to single pointer. This way we can spare several heavy memcpy
      commands.
    * DRBG: Entropy health tests for external entropy - only for security strength of 256b. That way
      the tests are performed over 1024 bits and not less.
    * DRBG: removed DRBG_EntroptyHealthtest call from the MISC_INIT DRBG self-test. This reduces boot
      time for the TIP.
    * DRBG: NCL_DRBG_* APIs may be called with NULL context. When the context is NULL, the NCL
      driver will use the internal global DRBG context. For that purpose, NCL_DRBG_CONTEXT_NULL_CHECK macro
      was added.
    * DRBG: Fixed healthtest of entropies shorter than 1024b (issue #513)
    * MISC: NCL module name changed from NCL 2.0 to "Nuvoton Cryptographic Library v2.0".
    * MISC: When any selftest fails, NCL enters fail mode and can be recovered only by successful completion
      of full selftest.
    * MISC: Removed the ST completion requirement from all Power, InitializeContext and
      FinalizeContext APIs of all modules. It is the user's responsibility to power on
      a module before running selftest.
