 NPCM8XX (Arbel) A35 BootBlock Build instructions
----------------------------------------------------------------------

BootBlock version: 0.6.0
Supported build modes: tip and no_tip. The default is no_tip.
Run all commands below from the Sources directory.

Prerequisites
-------------
Windows:
- GNU Make 4.3 or later and MinGW/MSYS tools, including bash, sed, mkdir, and rm.
  Add their bin directories to PATH. The scripts also check C:\MinGW\bin and
  C:\MinGW\msys\1.0\bin.
- Arm GNU Toolchain 13.2.Rel1 for aarch64-none-elf.
  Set CC_PATH to its installation directory or bin directory, or add its bin
  directory to PATH. Example:

    set "CC_PATH=C:\cross-compiler\arm-gnu-toolchain-13.2.rel1-mingw-w64-i686-aarch64-none-elf"

Linux:
- GNU Make 4.3 or later, a POSIX shell, bash, and standard GNU utilities.
- Arm GNU Toolchain 13.2.Rel1 for aarch64-none-elf.
  Set CC_PATH to the toolchain installation directory:

    export CC_PATH=/opt/arm-gnu-toolchain-13.2.Rel1-x86_64-aarch64-none-elf

Build process
-------------
Windows:
    call .\clean.bat
    call .\build.bat tip
    call .\build.bat no_tip

Linux:
    ./clean.sh
    ./build.sh tip
    ./build.sh no_tip

The Linux build script cleans previous build outputs before each build.
Save the outputs from a mode before building the other mode.
Only tip and no_tip are accepted; unsupported modes return an error.
Cleaning affects generated files under Sources, not the prebuilt release
images in the package-level Images directory.

Build outputs
-------------
Relative to the package root, rebuilt binaries are:
    Sources\Images\tip\arbel_a35_bootblock.bin
    Sources\Images\no_tip\arbel_a35_bootblock_no_tip.bin

Each build also produces .elf, .dat, .map, and .asm files beside its binary.
The package-level Images\tip and Images\no_tip directories contain the
prebuilt release images; building does not replace them.

Use the binary matching the board's TIP or NO_TIP boot configuration when
generating a complete flash image with IGPS:
    https://github.com/Nuvoton-Israel/igps-npcm8xx
